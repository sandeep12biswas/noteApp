Welcome to FlowNote

FlowNote is a note-taking app with a free-form canvas. Click anywhere on a page and start writing: there are no fixed lines or boxes to fight with.

Notes are organised the way you'd organise a binder:

  • Folders (left panel) hold related pages, and can contain sub-folders.
  • Pages (middle panel) are the notes inside the selected folder.
  • The editor (right) is the page itself: a canvas where every click on an empty spot starts a new block of text called a segment.

Everything is saved automatically as you type. There is no Save button.

  • Many more colours. The Page colour and segment colour menus now offer a grid of shades for ten colour families (darkest to lightest), your recently used colours, and a built-in colour wheel under More colours….
  • Delete a segment directly. Right-click a segment and choose Delete segment. Changed your mind? Click Undo, or press Ctrl+Z.
  • Page names can start with a lowercase letter, and keep the case you type.
  • Easier-to-see colour swatches. Every swatch now has a visible edge, so pale colours no longer blend into the menu.

Installing on Linux

Download FlowNote-<version>-linux-x86_64.run (the one-file installer), or the .tar.gz bundle that contains the same installer plus the individual packages.

The easy way: the one-file installer

  1. In your file manager, right-click the .run file and choose Properties → Permissions → Allow executing file as program. In a terminal you can run chmod +x FlowNote-*.run instead.
  2. Double-click the file. (Or run ./FlowNote-*.run in a terminal for a text-based installer with the same steps.)
  3. Read the welcome and release notice, then click Continue.
  4. Choose how to install:
    • For everyone on this computer installs a system package (Debian, Ubuntu, Linux Mint, Pop!_OS and similar). You'll be asked for your password.
    • Just for me needs no password and works on any distribution. FlowNote goes into your home folder.
  5. Wait a few seconds while FlowNote is copied, then choose whether to start it straight away.

FlowNote is now in your application menu (under Office), and you can also start it by typing flownote in a terminal.

If FlowNote is already installed, the installer offers to upgrade it (newer version) or repair it (same version). Your notes are never touched by an upgrade.

From the bundle folder (terminal)

Unpack the bundle and run its installer. Every question can also be answered with an option:

tar xzf FlowNote-<version>-linux-x86_64.tar.gz
cd FlowNote-<version>-linux-x86_64
./install.sh                 # guided install
./install.sh --appimage      # just for me, no password
./install.sh --deb           # for everyone (system package)
./install.sh --silent        # no questions; picks the best option for this system
./install.sh --help          # all options

Check that the download is intact with sha256sum -c SHA256SUMS in the bundle folder.

What gets installed where

Install typeProgramCommandMenu entry
For everyone (.deb)/opt/FlowNote/usr/bin/flownoteSystem-wide
Just for me (AppImage)~/.local/opt/flownote~/.local/bin/flownote~/.local/share/applications

The "just for me" install is an AppImage, which normally needs the FUSE 2 library to start quickly. If your system doesn't have it, the installer sets FlowNote up to unpack itself on each start instead. That works fine but takes a few seconds longer. For faster starts, run sudo apt install libfuse2t64 (Ubuntu 24.04 and later; libfuse2 on older releases), then run the installer again.

Every install is logged to ~/.cache/flownote-install.log.

Installing on Windows

Download FlowNote-<version>-windows-x64.zip and unzip it (right-click → Extract All…).

Using the setup wizard (recommended)

  1. Double-click FlowNote_<version>_x64-setup.exe.
  2. Because the preview installers aren't code-signed yet, Windows may show "Windows protected your PC". Click More info, then Run anyway.
  3. Pick a language, then follow the wizard: Welcome → release notice (click I Agree) → install folder → Start Menu folder.
  4. On the last page, tick Create desktop shortcut if you want one, and leave Run FlowNote ticked to start it now.

The setup wizard installs for your user account only and does not need administrator rights. You'll find FlowNote in the Start Menu, together with FlowNote User Guide, FlowNote Feature Guide and Uninstall FlowNote.

Using the MSI package

If your organisation prefers Windows Installer packages, double-click FlowNote_<version>_x64_en-US.msi instead. It installs for all users and needs administrator rights.

Unattended installs

FlowNote_<version>_x64-setup.exe /S
msiexec /i FlowNote_<version>_x64_en-US.msi /qn

Uninstalling FlowNote

Uninstalling FlowNote keeps your notes unless you choose to delete them. If you reinstall later, your notes are picked up again automatically.

On Linux

  • Run uninstall.sh from the bundle folder (double-click it, or run it in a terminal). It asks you to confirm, then asks whether to also delete your notes.
  • The "just for me" install keeps its own copy of the uninstaller, so you don't need the download: ~/.local/opt/flownote/uninstall.sh.
  • For the system package you can also use sudo apt remove flownote or your software centre.
./uninstall.sh                 # asks before removing, and about your notes
./uninstall.sh --keep-data     # removes FlowNote, keeps your notes
./uninstall.sh --remove-data   # removes FlowNote and your notes

On Windows

Use any one of these:

  • Start Menu → FlowNote → Uninstall FlowNote. On the confirmation page you can tick Delete the application data to remove your notes too.
  • Settings → Apps → Installed apps → FlowNote → Uninstall.
  • Double-click Uninstall FlowNote.cmd in the download folder. It finds either kind of install (setup wizard or MSI) and shows a small window with an Also delete my notes option.

From PowerShell:

powershell -ExecutionPolicy Bypass -File .\Uninstall-FlowNote.ps1
powershell -ExecutionPolicy Bypass -File .\Uninstall-FlowNote.ps1 -RemoveData
powershell -ExecutionPolicy Bypass -File .\Uninstall-FlowNote.ps1 -Silent -KeepData

A tour of the window

When you start FlowNote for the first time the window is empty. You'll create your first folder and page in the next chapter.

Once you have some notes, the window looks like this:

Folders and pages

Creating your first page

  1. Click + next to Pages (or right-click an empty part of a panel and choose New page).
  2. Choose New folder and type a folder name, or choose Existing folder and pick one. Click Next.
  3. Type the page name and click Create.

Page names must start with a letter, lowercase or capital (not a number or symbol), and keep the case you type: meeting notes stays meeting notes. Folder names are capitalised for you as you type: work becomes Work. The same page name can be used in different folders.

Adding folders and sub-folders

  • New folder: click + next to Folders, type a name, press Enter.
  • Sub-folder: hover over a folder and click its small +, or right-click the folder and choose New subfolder. Folders can be nested up to 7 levels deep.
  • Move a folder: drag it onto another folder, or onto empty space to make it a top-level folder.

Renaming, deleting and changing icons

  • Rename a folder from its right-click menu. To rename a page, edit its title at the top of the editor.
  • Delete a folder or page from its right-click menu. You're asked to confirm. Deleting a folder deletes the pages inside it.
  • Change a folder's icon: click the folder icon and pick a new one.

Natural sort order

Folders and pages are listed in "natural" order, so Ideas 2 comes before Ideas 10.

Writing on the canvas

Click anywhere and type

Click any empty spot on a page. A segment (a block of text) appears exactly there. Click inside it and start typing. Click somewhere else on the page to start another segment. Arrange segments side by side, in columns, or wherever suits your notes.

Moving, resizing, colouring and deleting segments

  • Move: drag the small circle at the segment's top-left corner.
  • Resize: drag the small bar on the segment's right edge.
  • Colour: right-click the segment (not on a misspelled word) and pick a colour. Its border and a soft background tint are coloured. The menu has nine quick picks, a grid of shades for ten colour families (darkest at the top), your recent colours, and More colours… for the colour wheel (see Page colour below). Choose None to remove the colour.
  • Delete: right-click the segment and choose Delete segment (at the bottom of the menu). This works for any segment, even one with text or a colour.

After you delete a segment, a Segment deleted message appears at the bottom of the window for a few seconds. Click Undo (or press Ctrl+Z while you're not typing in a segment) to bring it back exactly as it was. Click ✕, or wait for the bar to run out, to make the deletion final.

Empty segments still tidy themselves away: delete all of a segment's text and click elsewhere, and it disappears, unless it has a colour.

Format Painter: select text whose look you like, click the brush, then select the text you want to look the same. Double-click the brush to keep painting until you click it again.

The "/" menu

Type / at the start of a line (or after a space) to insert a block without reaching for the ribbon. Use the arrow keys and Enter, or click. The list includes text, headings, lists, a checklist, a quote, a code block, any plugin blocks you've installed, and Ask AI.

Code blocks

Insert a Code block from the "/" menu or the ribbon, then pick its language in the top-right corner for syntax highlighting.

Spell check

Misspelled words get a wavy red underline. Right-click one to see suggestions, or to add it to your dictionary.

Canvas and Linear mode

Each page has two ways to be viewed. Canvas mode (the default) is free placement. Linear mode shows the same segments as one continuous document, top to bottom, which is handy for reading or printing. Switch by clicking Canvas / Linear in the status bar.

Drawing and handwriting

Open the Draw tab to draw anywhere on the page with the mouse, a touchpad or a pen.

  • Pen draws a thin line, Marker a translucent, highlighter-style one, and Eraser removes strokes.
  • Pick a colour from the swatches.
  • Switch back to the Home tab to type again. Your drawing stays on the page.

Pictures and attachments

Copy a file or picture (for example in your file manager, or a screenshot) and paste it into a segment with Ctrl+V.

  • Screenshots and copied images are embedded straight away.
  • Other files ask how you want them: Attach as file shows a compact chip with the file name and size (click it to open the file), and Embed in note shows the file inline.
  • Resize an embedded picture by dragging its corner.

Attached files are copied into FlowNote's own data folder, so the note keeps working even if you move or delete the original.

Finding notes

Use the search box at the top of the Pages panel. The drop-down next to it chooses what to search:

  • Name finds pages whose name matches what you type.
  • Contents finds pages whose text contains it, across all folders.

Click a result to open it. Clear the search box to go back to the folder's page list.

Making FlowNote look the way you like

Light and dark theme

Click the theme button in the status bar to switch between System (follow your computer's setting), Light and Dark.

Page colour

On the View tab, click Page colour. Page colours show in the light theme.

  1. Under Apply to, choose This page or All pages (the default for every page that doesn't have its own colour).
  2. Pick a colour:
    • Paper: soft paper tones such as Ivory, Sepia and Mint.
    • Shades: ten colour families, each from darkest (top) to lightest (bottom). Dark colours are fine: the text turns light so it stays readable.
    • Recent: colours you recently chose on the colour wheel.
    • More colours…: opens the colour wheel.
  3. Use default (for this page) or White (for all pages) removes the colour.

On the colour wheel, drag across the wheel to choose the colour, use the Brightness slider to make it lighter or darker, or type an exact hex code such as #7dd3fc. The two squares compare the current and the new colour. Nothing changes until you click Apply; Cancel goes back to the palette.

If you choose a page colour that makes some coloured text hard to read, FlowNote tells you. Adjust fixes the colours for you, Show me highlights the affected text, and Keep leaves it as it is.

Zoom

The View tab has zoom out (−), zoom in (+) and a reset button that shows the current zoom level (50% to 200%).

Backup & Sync

Sync keeps an end-to-end encrypted copy of your notes in a place you choose, and keeps several computers in step. Your notes are encrypted on your computer before they leave it, so only your devices can read them, not the cloud provider.

  1. On the View tab, click Sync….
  2. Choose where to sync: OneDrive, Google Drive, or A folder on this computer (for example a Dropbox or Syncthing folder, or a network drive).
  3. For OneDrive or Google Drive, click Continue to … sign-in and sign in with your browser.
  4. Choose a passphrase. Use the same passphrase on every device you want to sync.
  5. Give this device a name, so you can tell your devices apart.

Keep your passphrase somewhere safe. Without it, nobody (including you) can read the synced copy. Your notes on this computer are unaffected.

The status bar shows the sync state: Synced, Syncing…, Not synced yet, Sync needs attention or Sync error.

  • Conflicts: if two devices edit the same segment at the same time, FlowNote keeps both versions and marks the other one with a badge. Keep what you need and delete the rest.
  • Large deletions: if another device deletes a lot at once, FlowNote pauses and asks before applying it here (Apply, Not now or Details).

Frequently asked questions

Does FlowNote need an internet connection?

No. Everything works offline. The internet is only used for Backup & Sync to OneDrive or Google Drive, and for AI services you choose to set up.

Will uninstalling delete my notes?

Not unless you ask it to. Both the Linux and Windows uninstallers keep your notes by default.

How do I move my notes to a new computer?

Set up Backup & Sync on both computers with the same passphrase. Or close FlowNote, copy the data folder (see Where your notes are stored) to the same place on the new computer, and start FlowNote there.

Can I use FlowNote without segments, like a normal document?

Yes. Switch the page to Linear mode in the status bar.

Is my data sent to an AI service?

Only if you add an AI provider yourself (Insert → ⚙), and only the text you ask it about. With Ollama (local), nothing leaves your computer. See the Feature Guide for details.
